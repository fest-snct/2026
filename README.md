# 開発の大まかな流れ
1. ワイヤーフレーム(ページデザインの基礎)を作る
2. ページごとの役割分担を行う
3. 環境構築(サーバーの設定やlocalhostの設定)
4. 個々人または共同での開発
5. リリース

# 補足
